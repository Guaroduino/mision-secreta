# 🕵️‍♀️ Misión Secreta — Entrenamiento Físico de Memoria Operativa

Aplicación interactiva gamificada para entrenar la memoria de trabajo y el seguimiento de instrucciones secuenciales en el mundo real, potenciada con **Google Gemini Vision** y **Web Speech / Web Audio API**.

## 🚀 Demo en Vivo

👉 **[https://Guaroduino.github.io/mision-secreta/](https://Guaroduino.github.io/mision-secreta/)**

## ✨ Características

- **Protocolo de 4 Fases Cognitivas:** Escuchar ➔ Repetir en voz alta (3 veces) ➔ Ejecutar en el mundo real ➔ Validar con cámara o con un adulto.
- **Integración opcional con Google Gemini (`gemini-3.8-flash`):**
  - Generación de misiones físicas nuevas de 2, 3 o 4 pasos.
  - Validación visual mediante la cámara web con Gemini Vision.
- **Modo Local / Sin Conexión:** Catálogo de misiones físicas preconfiguradas y validación local o por padres sin requerir API Key.
- **Efectos de sonido y narración por voz** integrados en el navegador.
